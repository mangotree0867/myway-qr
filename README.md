# 내 방식 QR : 범용 접근성 프로필 패스

QR 하나로, 어떤 키오스크든 내 방식으로.
2026 AI 라이프 솔루션 챌린지 출품작 (AI 라이프 아이디어 챌린지 수상 후보작 '내 방식 QR'을 AI로 구현)

- 테스트 URL: https://myway-qr.vercel.app
- 체험 순서: 키오스크 체험 → 예시 프로필(어르신, 저시력, 휠체어, 외국인) 누르기 → 화면 도우미에서 예시 사진으로 안내 받기

## 무엇을 하나요

| 기능 | 설명 | AI |
|---|---|---|
| 내 방식 프로필과 QR | 불편한 점을 고르거나 말하면 글씨 크기, 대비, 말 수준, 소리, 버튼 위치, 언어, 피할 재료 설정을 만들어 QR에 담습니다. 이름이나 장애 정보는 담지 않습니다. | 설정 에이전트 (Claude Haiku) |
| 내 방식 화면 엔진 | QR을 읽은 키오스크가 같은 메뉴를 한 화면 한 질문, 큰 글씨, 고대비, 아래쪽 버튼, 시간 제한 없음, 소리 안내로 다시 그립니다. | |
| 쉬운 말 다시 쓰기 | 메뉴 설명을 쉬운 말 2단계와 5개 언어로 다시 쓰고, 원문에 없는 사실을 지어냈는지 따로 검수합니다. | Claude Haiku |
| 말로 주문하기 | 말한 문장을 장바구니 동작(담기, 빼기, 되묻기)으로 바꿉니다. AI가 응답하지 않으면 규칙 기반 주문으로 자동 전환합니다. | 주문 에이전트 (Claude Haiku) |
| 화면 도우미 | QR을 지원하지 않는 키오스크 화면을 찍으면 지금 누를 버튼을 찾아 사진 위에 표시하고 소리로 안내합니다. | 비전 (Claude Sonnet) |

## 사전검증 결과 (eval/results)

| 항목 | 방법 | 결과 |
|---|---|---|
| 말로 주문 | 50문장 (줄임말, 사투리, 5개 언어, 되묻기 포함) | AI 98%, 규칙 기반 56% |
| 화면 도우미 | 8개 화면, 24개 목표, 정답 버튼 좌표 자동 추출 | 휴대폰 사진 조건 100%, 깨끗한 화면 87.5% |
| 쉬운 말 | 메뉴 18개, 어려운 말 46개 목록 | 어려운 말 58개 → 0개 (아주 쉬운 말) |
| 말로 설정 만들기 | 20문장 + 처음 보는 10문장 | 100% / 100% |
| 주문 시간 (추정) | KLM 시간값에 고령자 보정 (실측 아님) | 약 119초 → 60초, 말로 주문 약 28초 |

## 구조

```
app/            화면 (소개, 키오스크 체험, 프로필, QR 보기, 화면 도우미, 사용자 테스트)
app/api/        AI 서버 기능 (easy, order, lens, onboard)
lib/ai.ts       AI 기능 4가지의 지시문과 규칙 기반 대체
lib/llm.ts      Claude / Gemini 호출 어댑터 (구조화 출력)
lib/profile.ts  프로필 형식과 QR 인코딩
lib/data/       검수를 거친 쉬운 말 변환 결과
eval/           평가셋과 평가 스크립트, 결과
video/          시연 영상 녹화 스크립트
```

## 실행

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev
```

평가 다시 돌리기: `npx tsx eval/order_eval.ts`, `npx tsx eval/lens_eval.ts photo`, `npx tsx eval/easy_eval.ts`, `npx tsx eval/onboard_eval.ts`

## 사용 기술

Next.js, TypeScript, Claude API (텍스트, 비전, 도구 호출을 이용한 구조화 출력), 브라우저 음성 합성과 음성 인식, qrcode, jsQR, Vercel

## 데이터

별도 학습 데이터를 쓰지 않았습니다. 평가셋은 직접 만든 키오스크 시뮬레이터 화면과 직접 작성한 문장입니다. 문제 정의 통계는 한국소비자원(2022), 한국지능정보사회진흥원 2025 디지털정보격차 실태조사, 뉴시스(2026.1.27) 보도를 인용했습니다.
